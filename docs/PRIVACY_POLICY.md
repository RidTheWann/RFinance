# Privacy and Local Data

RFinance has no application account and is designed to keep portfolio records, settings, analysis, cache, documents, and logs on the local device.

Network access, when enabled in later releases, is limited to documented public information sources and optional explicitly configured local AI endpoints. Core financial calculations must not require cloud AI or a remote database.

Local application data is not uploaded by default. Users are responsible for the security of their Windows account, device, disk encryption, backups, and any files they explicitly export or share.

The initial build has no telemetry or analytics implementation. Any future telemetry requires a separately documented opt-in and privacy review.
